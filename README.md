## SmartStock & Sales Analytics

![Logo de SmartStock](./logo.png)

# Descripción:

SmartStock & Sales Analytics es una aplicación de escritorio desarrollada en Python para la gestión de inventario y el registro de ventas y entradas de productos.

El sistema permite administrar productos, consultar existencias, identificar productos con stock bajo, registrar entradas de mercancía y realizar ventas mediante un carrito de compras. También permite consultar el historial de movimientos para facilitar el control del inventario.

# Instalacion y ejecucion

1. Descargar el proyecto:

-Ingresar al repositorio de SmartStock & Sales Analytics en GitHub.

-Hacer clic en el boton Code.

-Seleccionar Download ZIP.

-Extraer el archivo ZIP descargado en la ubicacion deseada.

2. Abrir la carpeta del proyecto:

-Abrir la carpeta extraida con Visual Studio Code o desde una terminal. Asegurarse de estar dentro de la carpeta donde se encuentran los archivos app.py y requirements.txt.

3. Instalar las dependencias:

-Abrir una terminal dentro de la carpeta del proyecto y ejecutar el siguiente comando:
py -m pip install -r requirements.txt

4. Ejecutar la aplicacion:

-En la misma terminal, ejecutar:
py app.py

Una vez completados estos pasos, SmartStock & Sales Analytics estara lista para utilizarse
